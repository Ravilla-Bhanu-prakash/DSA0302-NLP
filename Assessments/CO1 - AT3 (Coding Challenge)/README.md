## Execution Guide

### Running via Python CLI
```bash
# Navigate to the Programs folder
cd "Assessments/CO1 - AT3 (Coding Challenge)/Programs"

# Run any problem script with the sample input
python 01_Tokenization_Regex.py
python 02_Simulate_FSA.py
python 03_Inflectional_Morphology.py
python 04_Morphological_Parsing.py
python 05_Porter_Stemmer_Step1.py
```

### Running via Jupyter Notebook
You can open any `.ipynb` file in Google Colab, VS Code, or JupyterLab:
```bash
jupyter notebook 01_Tokenization_Regex.ipynb
```
